## 🔧 Customization

### For Developers

To add a new theme, edit `frontend/utils/themes.js`:

```javascript
newTheme: {
  value: 'newtheme',
  label: 'New Theme',
  icon: '🎨',
  emoji: 'related emojis',
  description: 'Theme description',
  primary: '#FF0000',
  secondary: '#00FF00',
  light: '#FFEEEE',
  dark: '#330000',
  gradient: 'linear-gradient(...)',
  background: 'radial-gradient(...)',
  borderColor: '#FF0000',
  shadowColor: 'rgba(255,0,0,0.3)',
  accentColor: '#FFFF00'
}
```
