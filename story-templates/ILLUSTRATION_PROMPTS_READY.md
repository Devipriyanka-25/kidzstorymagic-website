## PROMPT FORMATTING FOR AI ART GENERATION

### Structure for Midjourney, DALL-E, or Adobe Firefly

**Full Prompt Template:**
```
[CHARACTER DESCRIPTION in detail], [ENVIRONMENT & SETTING], [LIGHTING DIRECTION 
& COLOR PALETTE], [MOOD & ATMOSPHERE], [ARTISTIC STYLE & TECHNIQUE], [QUALITY 
LEVEL], [NARRATIVE/FOCUS]

--ar [ASPECT RATIO] --q 2 --s 1000
```

**Example:**
```
Whimsical animated child character with warm peachy skin, large expressive eyes 
with sparkle highlights, soft hair flowing, stylized proportions (4-heads-tall), 
rendered in watercolor-digital painting style with soft edges. Standing in awe 
at entrance to mystical enchanted forest. Tall glowing trees emit bioluminescent 
light in deep greens and ethereal blues. Gentle mist at ground level. Magical 
floating particles suspended in air. Golden-hour twilight lighting creating 
phosphorescent glow. Mood: enchanted, magical, safe wonder. Composition 
emphasizes towering trees and vastness. Cinematic professional children's book 
illustration, museum-quality, fantasy digital painting style. Focus: sense of 
wonder and magical adventure beginning. --ar 4:5 --q 2 --s 1000
```

## Notes for Implementation

### Backend Integration
Store complete prompts in database/template:
```javascript
const storyTemplates = {
  adventure: {
    pages: [
      {
        page: 1,
        title: "The Discovery",
        storyText: "[Story text with placeholders]",
        illustrationPrompt: "[FULL PROMPT ABOVE]"
      },
      // ... more pages
    ]
  }
};
```

### Frontend Usage
Display illustrations generated from these prompts:
```javascript
// When story is generated, trigger illustration generation
const illustrationPrompt = replacePlaceholders(
  template.pages[pageNum].illustrationPrompt,
  { childName, setting, ... }
);

// Send to AI illustration service or display to illustrator
generateIllustration(illustrationPrompt);
```

### Professional Delivery
- Provide complete prompts to illustrators
- Include character reference page
- Specify artistic style strongly
- Request 3-5 variations if budget allows
- Final illustrations should be 300 DPI for print

## Quality Assurance Checklist for Prompts

Each prompt should include:
- [ ] Specific character description (not generic)
- [ ] Detailed environment with foreground/mid/background
- [ ] Clear lighting direction and color palette with hex codes
- [ ] Defined mood and emotional atmosphere
- [ ] NO photorealistic or real face descriptions
- [ ] Explicit "watercolor," "digital painting," "animation" style
- [ ] Quality level stated (professional, museum-grade, cinematic)
- [ ] Narrative purpose clear
- [ ] Age-appropriate and child-safe
- [ ] Consistency check with other pages in story
